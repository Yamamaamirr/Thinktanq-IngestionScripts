# thinqtank — Candidate Site Detection Engine

End-to-end spatial pipeline that turns national infrastructure and land-use data
into a ranked set of candidate sites for large-format, power-intensive
infrastructure development. Five-state Phase 1 coverage (CA, TX, AZ, NV, VA),
~125k greenfield candidates + 6.6k reuse-node candidates, scored on a
common composite framework.

## How it works

The pipeline runs as a sequential funnel. Each stage narrows the search area
before the next one runs.

```
ingestion_scripts/                Download and normalise national datasets into parquet.
candidate_areas/scripts/          Build keep-zones, exclusion mask, candidate polygons.
candidate_areas/enrichment_scripts/  Per-candidate enrichment (slope, seismic, anchors, …).
candidate_areas/scoring_scripts/  Kill gates, four sub-scores, composite, action labels,
                                  reason codes, three-format export, verification.
```

Final output: `candidates_final.parquet` / `.csv` / `.fgb` plus a QA report PDF.

A second layer — **infrastructure reuse nodes** — runs alongside greenfield and
is merged into the final deliverable. See [Reuse-node layer](#reuse-node-layer)
below.

## Pipeline stages

| Stage | Folder / script | What it does |
|---|---|---|
| 1-4 | `candidate_areas/scripts/Step1-4_*.py` | Filter active-queue substations, buffer them (25 km), buffer 345 kV+ transmission corridors (10 km), union into national keep-zones. |
| 5 | `candidate_areas/scripts/Step5_*.py` | Build exclusion mask: FEMA floodway/VE, open water, PAD-US GAP 1-2, slope >15%, NWI wetlands. Plus post-filters for public GAP-3/4 (PDF Rule 8), airport runway protection zones (PDF Rule 10), and TIGER major roads. |
| 6 | `Step6_subtract_exclusions.py` | Subtract exclusion mask from keep-zones (state-tiled, 25 km fishnet, 500 m overlap, set_precision 1 m). |
| 7 | `Step7_*.py` + `Step7d_subdivide_megas.py` | CDL classification, connected-component candidate polygons, subdivision of polygons ≥5,000 ac via 4 km grid. |
| 1A-1J | `candidate_areas/enrichment_scripts/` | Per-candidate slope, seismic (NSHM23), drought (USDM), adjacency (PAD-US/wetland/floodway/FEMA-AE/radar), transmission (500/345/230 kV), pipelines (PHMSA tiered), Class 1 rail, water service, utility anchors with banded distance decay, original-vs-buildable acreage. |
| 2A-2G | `candidate_areas/scoring_scripts/` | Kill gates, four weighted sub-scores, composite renormalised to 90%, confidence (worst-of-3), recommended_action incl. Shortlist band, actionability_status, top_reason_codes, dataset versioning. |
| 3A-3B | `Step3A_export_csv_geoparquet.py`, `Step3B_apply_slope_hard_exclusion.py` | Final slope hard-exclusion (PDF Rule 13), three-format export (GeoParquet + CSV + FlatGeobuf). |
| Verify | `Step3_final_verify.py`, `Step4_audit_data.py`, `Step5_audit_attributes.py`, `Step6_final_deep_verify.py`, `Step7_owen_conformance_check.py` | 95+ checks across schema, vocabulary, formula, geometry, PDF rule compliance. |

The full methodology, scoring framework, distributions, and known caveats are
in `candidate_areas/outputs/Phase1_QA_Report.pdf` (generated by
`candidate_areas/scripts/generate_qa_pdf.py`).

## Reuse-node layer

The reuse-node layer captures the four reuse categories in Owen's spec:
retired/retiring coal & gas plants (EIA 860), operating/retired nuclear
(NRC + EIA), EPA RE-Powering brownfields / landfills / abandoned mines, and
large industrial-zoned sites with grid/rail/water adjacency (OSM polygons).

```
ingestion_scripts/eia_form860/ingest_eia_reuse_nodes.py     EIA 860 retired/retiring power plants
ingestion_scripts/nrc_nuclear/ingest_nuclear_sites.py        Nuclear sites
ingestion_scripts/epa_repowering/ingest_epa_repowering.py    EPA RE-Powering registry
ingestion_scripts/osm_industrial/ingest_osm_industrial.py    OSM landuse=industrial / landfill / quarry / power=plant / man_made=works
ingestion_scripts/usgs_slope/ingest_slope_per_reuse_node.py  USGS 3DEP slope per reuse-node polygon

candidate_areas/reuse_node_scripts/
  StepR1_load_and_normalize.py       Unify 4 sources -> reuse_nodes_raw.parquet
  StepR2_define_footprints.py        Strict point-in-polygon to OSM -> polygon footprint per row
  StepR2b_clean_reuse_nodes.py       6 cleanups (intra-source dedup, LOW conf drop, EPA <50ac,
                                     OSM renewables, OSM active military/prison, alias preservation)
  StepR2c_verify_clean.py            32 deep verification checks
  StepR3A-J + StepR3_merge.py        Per-reuse-node enrichment (slope/seismic/drought/adjacency/
                                     transmission/pipelines/rail/water/utility anchors/acreage)
  StepR4_reuse_risk_fields.py        Four reuse-specific risk flags
  StepR5A-F + StepR5_verify.py +     Kill gates, 5 subscores (utility/buildability/supporting_infra/
        StepR5_action_audit.py       dev_risk/reuse_environmental), composite, confidence,
                                     recommended_action, top_reason_codes
  StepFinal_merge_greenfield_and_reuse.py    Merge with greenfield into final_candidates_phase1.parquet
  StepFinal_export.py                GeoPackage + CSV + actionable subset for analyst consumption
```

| Stage | Folder / script | What it does |
|---|---|---|
| R1 | `StepR1_load_and_normalize.py` | Unify 4 source parquets into one schema with prefixed `site_id`, single CRS |
| R2 | `StepR2_define_footprints.py` | Strict point-in-polygon containment to OSM industrial polygons; polygon adopted when match exists, otherwise square envelope sized by acreage (EPA) or capacity template (EIA). Provenance tagged in `geometry_source` |
| R2b | `StepR2b_clean_reuse_nodes.py` | 6 cleanups: intra-source 100m centroid dedup with alias preservation, drop LOW confidence, drop EPA <50 ac, drop active OSM solar/wind/military/prison/proving sites |
| R2c | `StepR2c_verify_clean.py` | 32 schema, geometry, source-consistency, cleanup-gate, and polygon-overlap checks |
| R3A–R3J | `StepR3*_*.py` + `StepR3_merge.py` | Per-reuse-node enrichment mirroring greenfield Step1A–1J; outputs to `reuse_node_enrichment_outputs/` |
| R4 | `StepR4_reuse_risk_fields.py` | Derives `environmental_review_required`, `legacy_asset_risk_flag`, `decommissioning_status_known`, `known_contamination_flag` from source / asset_type / EPA program |
| R5 | `StepR5A_kill_gates.py` … `StepR5F_composite.py` | Kill gates, 5-component composite (recalibrated: util 25 / build 15 / supp 15 / risk 15 / reuse_env 20). New action `Reuse Diligence` for flagged sites scoring ≥60 |

**Why the reuse-node weights differ from greenfield.** Reuse polygons are by
definition near grid infrastructure. With greenfield's 40% utility weight, ~78%
of reuse rows pinned at `utility_score = 100` and the composite collapsed.
Recalibration: utility weight dropped 40→25%, per-anchor contribution capped at
30 (so site needs ≥4 good anchors to max out), and `reuse_environmental_score`
promoted from 0.12·0.15 buried in dev_risk to a standalone 20% composite slot
with a -45 contamination penalty. Effect: contam-vs-clean composite delta went
from 3.85pt → 18.26pt, top-tier `Shortlist` action now correctly excludes
heavily-contaminated sites.

**Final deliverable.** `candidate_areas/outputs/final_candidates_phase1.parquet`
contains both layers in one table with `candidate_type ∈ {greenfield, reuse_node}`.
GeoPackage + CSV exports are written to `candidate_areas/outputs/exports/` and
`candidate_areas/reuse_node_outputs/exports/`.

### ISO queue pipeline — `gridstatus_iso_queues/`

The most involved ingestion module. Four scripts work in sequence:

| Script | Role |
|---|---|
| `gridstatus_iso_queues.py` | Downloads raw queue data from CAISO, ERCOT, PJM, MISO, ISONE, NV Energy. Normalises to a unified schema. |
| `iso_anchor_match.py` | Fuzzy-matches each queue entry's substation name to a real HIFLD location. Distinguishes true substations from line-based POIs (e.g. "A–B 345 kV"). Assigns match confidence: high / medium / low. |
| `anchor_queue_enrichment.py` | Aggregates matched queue rows per substation. Produces `anchor_queue_stats.parquet` and `zone_queue_stats.parquet` (territory-level fallback for ERCOT zones and NV Energy). |
| `build_supplemental_substations.py` | Builds a supplemental substation layer from EIA 860 and OSM to fill HIFLD gaps. |

**Scoring approach:** for each candidate site, all substations within 50 km are
collected and weighted by banded distance decay (0-5 km strong = 1.00, 5-10 km
moderate = 0.67, 10-25 km weak = 0.33, 25-50 km regional context = 0.10). The
weighted active MW is summed across all nearby anchors. When no matched
substations are found within range, a zone-level fallback (ERCOT CDR zone or NV
Energy territory) is used and flagged as `zone_fallback_used=True`.

For ERCOT and LBNL Queued-Up data, the gridstatus script falls back to local
xlsx files if the live APIs are blocked. Set `ERCOT_GIS_PATH` and
`LBNL_QUEUE_PATH` env vars to point to the files, or drop them at
`ingestion_scripts/gridstatus_iso_queues/manual_downloads/ercot_gis_report.xlsx`
and `lbnl_queue.xlsx` (default fallback location).

## Scoring framework

Four weighted sub-scores combine into a composite (PDF May 6, sec. 19):

| Sub-score | Weight | Inputs |
|---|---|---|
| utility_score | 40% | Anchors within 50 km × queue MW tier × status × voltage × distance decay × match confidence |
| buildability_score | 20% | land_cover + constraint + slope_tier + building_footprint |
| supporting_infra_score | 15% | 0.35·transmission + 0.25·pipeline + 0.20·rail + 0.20·water |
| dev_risk_score | 15% | 0.25·seismic + 0.20·drought + 0.15·radar + 0.15·padus + 0.15·wetland + 0.10·floodway |
| site_control_score | 10% | Deferred to Phase 2 (parcel data) |

`composite = (0.40·u + 0.20·b + 0.15·s + 0.15·d) / 0.90`. The 0.90 divisor
renormalises over the observable weight so candidates aren't capped while the
parcel module isn't built.

Action labels (PDF Rule 29): **Ignore / Monitor / Manual Review / Parcel Pull /
Utility Desk Check / Ownership Review / Reuse Diligence / Shortlist**.
Actionability statuses (Owen May 11): do_not_pitch / internal_diligence_only /
apn_owner_pull_required / broker_verify_required / nda_teaser_possible /
buyer_ready_with_caveats.

## Data notes

* Parquet files, cache directories, raw shapefiles, ArcMap/QGIS workspace files
  (`.lyrx`, `.mxd`, `.aprx`, `.qgs`), PDFs, and generated `RUN_LOG.md` / audit
  reports are excluded via `.gitignore`. Run the ingestion scripts locally to
  regenerate.
* Output coordinate reference system is EPSG:5070 (NAD83 / Conus Albers).
  Centroids are reprojected to EPSG:4326 for `centroid_lon` / `centroid_lat`.
* Pipeline diameters are estimated from operator tier and pipeline classification
  (NPMS access is restricted to government/operator entities). The field
  `pipeline_diameter_estimated = True` flags this.
* The NOAA Drought Monitor cache auto-refreshes after 7 days (weekly USDM
  release cycle).
* FERC 714 downloads a 226 MB hourly file once; subsequent runs use the cache.
* PJM queue data is cached locally; do not rely on the embedded browser key for
  production calls — refresh on a defined schedule.
* Target states for Phase 1: **CA, TX, AZ, NV, VA**.
